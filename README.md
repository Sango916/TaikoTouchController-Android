# 太鼓タッチコントローラー (Taiko Touch Controller)

Android端末を、PCや他のAndroid端末、または同一端末上のゲームアプリ向けの低遅延な太鼓コントローラーとして利用できるようにするAndroidアプリケーションです。AYN Thor等の2画面デバイスの下画面コントローラーとしても動作します。

本プロジェクトのソースコードおよびアプリケーションは、**Google AI Studio** を活用して開発されています。

---

## 主な機能と特徴

- **直感的なタッチ操作と打感設定**
  - ドン（面）/ カッ（フチ）の左右叩き分け
  - 大音符の片手同時押しアシスト（面・フチそれぞれで判定範囲の調整が可能）
  - 打撃時の触覚フィードバック（バイブレーション強度調整）および効果音再生
  - 画面の向き（縦画面・横画面）に応じたドラムサイズ・表示位置のプリセット保存とカスタマイズ
  - 描画軽量モード（波紋エフェクト等の描画負荷を抑制し、高速連打時や低スペック端末でのレスポンスを向上）

- **接続モード**
  - **この端末 (Shizuku / root)**: 同一端末上でバックグラウンド動作し、Shizuku経由で他のゲームアプリへキーボードまたはゲームパッド入力を直接送信
  - **PC (USB有線接続)**: 端末とPCをUSB接続し、ADBポートフォワーディング経由でWindows / macOS / Linux上のゲームへ低遅延キー入力を送信（PC側受信スクリプトはアプリ内からワンクリックでコピー可能）
  - **別のAndroid端末 (有線 / 無線)**: 1台をコントローラー送信側、もう1台を受信側（ゲーム実行端末）としてUSBケーブルまたはWi-Fi経由で連携
  - **なし (ローカルデモ)**: 外部通信を行わず、画面上の叩き心地や設定の確認のみを行うモード

- **オーバーレイとフローティングバブル**
  - ゲーム画面の上にコントローラーや設定ボタンを重ねて表示するフローティングオーバーレイ機能
  - 不透明度（透明度）の調整に対応

## 動作環境

- **対応OS**: Android 8.0 (API レベル 26) 以上
- **ターゲットSDK**: Android 14 (API レベル 34)

---

## 開発環境・技術スタック

- **開発ツール**: Google AI Studio / Android Studio
- **言語**: Kotlin
- **UI フレームワーク**: Jetpack Compose (Material 3)
- **ビルドツール**: Gradle (Kotlin DSL)

### ビルドコマンド

```bash
# デバッグビルド (APKの生成)
./gradlew assembleDebug

# 単体テストの実行
./gradlew testDebugUnitTest
```
